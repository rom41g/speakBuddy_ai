# SpeakBuddy AI

Голосовой тренажёр английского языка для 2–4 классов, уровни Pre-A1 и A1. Прототип разработан для практической части статьи «Потенциал ИИ-чат-ботов в развитии навыков устной речи на английском языке у младших школьников».

[Демоверсия на GitHub Pages](https://rom41g.github.io/speakBuddy_ai/)

## Упражнения

| Режим | Что делает ученик |
| --- | --- |
| AI Conversation | Отвечает на вопросы по теме юнита и использует его слова в речи. |
| Свободный чат | Выбирает тему разговора, задаёт вопросы и общается без счётчика реплик. |
| Role Play | Разыгрывает ситуацию по юниту, например беседует с экскурсоводом или выбирает снаряжение. |
| Describe the Picture | Описывает две карточки словами юнита. |
| Guess the Word | Угадывает слово юнита по определению и может попросить первую букву. |
| Pronunciation Lab | Слушает слово или фразу по юниту, записывает себя и при подключённом модуле получает фонетическую обратную связь. |
| Режим учителя | Выбирает материал занятия, подсказки и отображение баллов. Видит счётчики текущего занятия. |

Интерфейс переключается между русским и английским. Микрофон включается одним нажатием. Разрешение на доступ запрашивает браузер. Можно сделать короткую паузу и продолжить ту же реплику. Нажми «Остановить запись», чтобы отправить её сразу. Перед отправкой SpeakBuddy восстанавливает заглавные буквы и базовую пунктуацию. Бадди начинает озвучивать готовую часть ответа во время генерации. Расшифровку можно открыть кнопкой «Текст ответа». Настройка «Озвучка текста» управляет ответами на напечатанные сообщения. Динамик рядом с ответом повторяет реплику. Браузер хранит настройки и суммарные счётчики. Реплики и записи находятся в памяти вкладки на время упражнения. Распознавание использует `en-GB` и может выполняться сервисом браузера. При недоступном микрофоне можно печатать ответы.

Бадди озвучивает диалог системным голосом English (United Kingdom), доступным в браузере. Конкретный голос зависит от устройства. Если британского голоса нет, проверьте настройки озвучки устройства. [Системные голоса браузера](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis/getVoices)

На iPhone разрешение на микрофон задаётся в Safari для конкретного сайта. Откройте SpeakBuddy, в меню страницы выберите «Настройки веб-сайта», затем «Микрофон» → «Разрешить». [Руководство Apple](https://support.apple.com/en-euro/guide/iphone/iphb01fc3c85/ios)

В разделе **Словарь** выбери юнит или введи английское слово либо русский перевод. В карточках есть британская IPA, перевод в учебном значении и отдельное аудио. Карточку также можно вызвать в разговоре вопросом `How do you pronounce pencil case?` или `Что значит pencil case?`. Для разных форм `read` доступны отдельные кнопки воспроизведения. Звуки для словарных карточек воспроизводятся из записей. Для диалогов применяется голос Бадди.

**Свободный чат**, **AI Conversation**, **Role Play** и **Describe the Picture** генерируют ответы с учётом последних реплик. В упражнениях модель получает тему, лексику юнита и уровень ученика. При доступности используется встроенная модель браузера. В остальных случаях SpeakBuddy готовит локальную модель в фоне сразу после открытия сайта. Первый запуск скачивает около 397 МБ. При следующих открытиях того же адреса модель читается из хранилища браузера. Скачивание и запуск из хранилища показываются разными статусами. Текстовый ответ появляется по мере готовности предложений. Обработка реплик выполняется в браузере, если учитель не включил OpenRouter. При сбое исходная реплика остаётся в поле для повторной отправки. [Qwen3-0.6B](https://huggingface.co/Qwen/Qwen3-0.6B) · [Квантованная модель](https://huggingface.co/unsloth/Qwen3-0.6B-GGUF) · [Wllama](https://github.com/ngxson/wllama)

### Academy Stars

При регистрации ученик выбирает учебник **Academy Stars 1, 2, 3 или 4** по обложке. Профиль хранится в браузере. AS1 и AS2 соответствуют Pre-A1, AS3 и AS4 соответствуют A1. Для каждой книги заданы свои грамматические конструкции, примеры слов и длина ответа. В свободном чате действует учебник ученика, в упражнении учитывается учебник выбранного юнита. Обложки Pupil’s Book принадлежат Macmillan Education.

В словаре 702 слова и выражения. В него вошла лексика 40 юнитов Pupil’s Book, дополнительных уроков и карточек Academy Stars 1, 2 и 4, а также карточек AS3 для юнитов 1–4. Для юнитов AS3 5–10 в словарь добавлены слова из разделов Reading и Language in use. Переводы учитывают значение слова в уроке. Источники британской IPA включают Wiktionary через Wiktextract/Kaikki, Cambridge Dictionary и британские фонемы eSpeak NG. Составные выражения также транскрибированы по словарным формам. Источник указан в карточке. Данные IPA, адаптированные из Wiktionary, распространяются по CC BY-SA 4.0. [Kaikki и ссылка для научного цитирования](https://kaikki.org/dictionary/English/) · [Лицензия CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)

Каждая словарная форма воспроизводится из готового MP3. Файлы сгенерированы голосом Piper `en_GB-cori-medium` по фонемам британской IPA. Записи сохраняют начало и конец каждого звука. Тихий /θ/ и /t/ на границах слов усилены по позициям фонем. Громкость речи выровнена. Для повторной генерации нужны `piper-tts[alignment]==1.8.0`, FFmpeg и модель с конфигурацией. Команда `python scripts/render_dictionary_audio.py /path/to/en_GB-cori-medium.onnx` пересобирает весь словарь. После пути можно передать отдельные слова. Голос основан на записях Cori Samuel для LibriVox, вошедших в набор Hi-Fi Multi-Speaker English TTS (CC BY 4.0). [Модель Cori](https://huggingface.co/rhasspy/piper-voices/tree/main/en/en_GB/cori/medium) · [Набор Hi-Fi TTS](https://www.openslr.org/109/)

Для `thirsty`, `bus stop` и `do up your coat` выбраны синтезированные образцы Southern English Female. Для их повторной генерации рядом с Cori нужны `en_GB-southern_english_female-low.onnx` и соответствующий JSON. Источник голоса — набор британских и ирландских диалектов Google, 2018–2019. Эти три MP3 распространяются по CC BY-SA 4.0. [Модель Southern English Female](https://huggingface.co/rhasspy/piper-voices/tree/main/en/en_GB/southern_english_female/low) · [Набор OpenSLR 83](https://www.openslr.org/83/)

Пункт **Свободная практика** возвращает к общим темам и упражнениям. Для уже развёрнутого Cloudflare Worker повторите развёртывание, чтобы ИИ и фонетический анализ получили новый каталог.

## Локальный запуск

Двойной щелчок по `index.html` открывает демоверсию на GitHub Pages. Для запуска с компьютера на Windows дважды щёлкните `start-speakbuddy.cmd`. Он запустит Vite и откроет локальную страницу в браузере. Оставьте окно терминала открытым, пока пользуетесь ботом.

Для локального запуска нужен Node.js 24. Те же команды можно выполнить вручную из папки проекта.

```sh
npm ci
npm run dev
```

Откройте `http://127.0.0.1:5173`. Генеративные диалоги в браузере, словарь, угадывание и запись с воспроизведением доступны без ключей. `npm run build` проверяет TypeScript и собирает сайт в `dist/`.

## Подключение ИИ и фонетического анализа

Публичная версия работает на GitHub Pages. GitHub Actions собирает и публикует `dist/`. В настройках репозитория источником Pages служит GitHub Actions. Для облачных функций запросы идут в Cloudflare Worker. Он хранит ключи, ограничивает частоту обращений и требует отдельный код доступа к демонстрации.

### ИИ-диалог через OpenRouter

1. Для локальной проверки скопируйте `.dev.vars.example` в `.dev.vars`. Задайте `OPENROUTER_API_KEY` и случайный `DEMO_ACCESS_CODE` длиной от 16 символов. Во втором терминале запустите `npm run worker:dev` и обновите страницу.
2. Для сайта войдите в Cloudflare Wrangler через `npx wrangler login`, затем запустите `npm run worker:deploy`. Сохраните секреты командами `npx wrangler secret put OPENROUTER_API_KEY` и `npx wrangler secret put DEMO_ACCESS_CODE`.
3. В `Settings → Secrets and variables → Actions → Variables` задайте `VITE_API_BASE_URL` с HTTPS-адресом Worker. Запустите workflow публикации снова. Если изменился домен сайта, обновите `ALLOWED_ORIGINS` в `wrangler.toml`.
4. В режиме учителя введите код демонстрации и включите облачные функции. Попросите взрослого отвечать вымышленными данными.

Основная модель — `google/gemma-4-31b-it:free`. При недоступности модели сервер пробует `openrouter/free`. При сбое OpenRouter сайт использует браузерную модель. Идентификатор модели доступен в ответе API. Модель работает с текстом и может дать краткую лексико-грамматическую подсказку.

[Модель Gemma в OpenRouter](https://openrouter.ai/google/gemma-4-31b-it:free) · [Ограничения OpenRouter](https://openrouter.ai/docs/api/reference/limits)

### Локальное произношение через Pronunciada

1. Установите Python и выполните `python -m pip install pronunciada`.
2. Запустите `pronunciada serve --host 127.0.0.1 --port 8765 --azure-compat`. При первом анализе инструмент может скачивать модель. Для демонстрации сделайте одну пробную запись заранее.
3. В `.dev.vars` задайте `PRONUNCIADA_LOCAL="true"`. Запустите `npm run worker:dev` и `npm run dev`, затем откройте `http://127.0.0.1:5173`. После записи нажмите «Проанализировать локально».

В этом режиме запись передаётся локальному процессу на том же компьютере. Баллы Pronunciada и Azure получены разными моделями и требуют самостоятельной калибровки для исследовательского сравнения. [Документация Pronunciada](https://github.com/moglearn/pronunciada/blob/main/docs/AZURE_COMPAT.md)

### Облачное произношение через Azure Speech

Укажите `AZURE_SPEECH_KEY`, `AZURE_SPEECH_RESOURCE` (имя ресурса Speech) и `DEMO_ACCESS_CODE` в `.dev.vars` для локальной проверки или сохраните их командой `npx wrangler secret put ИМЯ` при публикации Worker. Код и согласие на облачные функции вводятся в режиме учителя. Кнопка анализа отправляет в Azure короткую запись и заранее заданный текст фразы. Оценка `en-GB` отображается по словам. Доступность и тарификацию нужно проверить для своего ресурса. [Документация Microsoft](https://learn.microsoft.com/en-us/azure/ai-services/speech-service/how-to-pronunciation-assessment)

### Поиск британской IPA через Cambridge Dictionary

Это дополнительная возможность для слов вне учебного словаря. Для неё укажите лицензированный `CAMBRIDGE_API_KEY`, код подключённого словаря `CAMBRIDGE_DICTIONARY` и `DEMO_ACCESS_CODE` в `.dev.vars`. При публикации Worker сохраните ключ через `npx wrangler secret put CAMBRIDGE_API_KEY`. В режиме учителя введите код демонстрации и включите облачные функции. [Официальный Cambridge Dictionary API](https://dictionary.cambridge.org/develop)

## Сценарий технической демонстрации

1. Выберите **Academy Stars 2 → 1. In the wild** и откройте **AI Conversation**. Ответьте `There are two kangaroos.` и включите подсказку со словами юнита.
2. Откройте **Role Play**, сыграйте посетителя парка с дикими животными и посмотрите счётчики в режиме учителя. Для демонстрации грамматической подсказки выберите **Свободная практика → AI Conversation → Животные** и введите `My favourite animal is dog.`
3. Выберите **Academy Stars 3 → 6. Under the sea**. В **Describe the Picture** опишите карточки. В **Guess the Word** послушайте загадку, при необходимости спросите `What is the first letter?` и назовите слово.
4. В **Pronunciation Lab** прослушайте образец выбранного юнита, запишите фразу и воспроизведите запись. При подключённом анализе проверьте оценку, включив отображение баллов в режиме учителя.

Для статьи можно протоколировать тестовые реплики, тему, уровень, идентификатор модели, удержание темы и уместность подсказки. Техническая демонстрация показывает функции прототипа. Педагогическую эффективность необходимо проверять отдельно по данным апробации. Для демонстрации используйте обезличенные записи взрослых.
