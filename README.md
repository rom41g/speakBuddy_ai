# SpeakBuddy AI

Голосовой тренажёр английского языка для 2–4 классов, уровни Pre-A1 и A1. Прототип разработан для практической части статьи «Потенциал ИИ-чат-ботов в развитии навыков устной речи на английском языке у младших школьников».

[Демоверсия на GitHub Pages](https://rom41g.github.io/speakBuddy_ai/)

## Упражнения

| Режим | Что делает ученик |
| --- | --- |
| AI Conversation | Отвечает на вопросы по теме юнита и использует его слова в речи. |
| Свободный чат | Выбирает тему разговора, задаёт вопросы и общается без счётчика реплик. |
| Role Play | Разыгрывает ситуацию по юниту, например беседует с экскурсоводом или выбирает снаряжение. |
| Describe the Picture | Описывает две карточки словами юнита. |
| Guess the Word | Угадывает слово юнита по определению и может попросить первую букву. |
| Pronunciation Lab | Слушает слово или фразу по юниту, записывает себя и при подключённом модуле получает фонетическую обратную связь. |
| Режим учителя | Выбирает учебник, юнит, сложность, подсказки и отображение баллов. Видит счётчики текущего занятия. |

Интерфейс переключается между русским и английским. Нажми на микрофон и скажи реплику. Когда браузер распознает её, Бадди автоматически отправит реплику и ответит голосом. Расшифровку можно открыть кнопкой «Текст ответа». Настройка «Озвучка текста» управляет ответами на напечатанные сообщения. Динамик рядом с ответом повторяет реплику. Браузер хранит настройки и суммарные счётчики. Реплики и записи находятся в памяти вкладки на время упражнения. Распознавание речи использует `en-GB` и зависит от браузера и его сервиса. При недоступном микрофоне можно печатать ответы.

Бадди выбирает британский голос `en-GB` браузера. В режиме учителя можно выбрать британский голос Emma, который также используется, если голос браузера недоступен. При первом использовании Emma браузер загружает модель (около 92 МБ) и синтезирует речь на устройстве. [Документация Kokoro](https://github.com/hexgrad/kokoro/blob/main/kokoro.js/README.md)

Спроси `How do you pronounce schedule?` или напечатай `Как произносится слово schedule?`. Бадди озвучит слово и покажет британскую IPA с указанием источника. Для слов, которых нет в подготовленной подборке, демоверсия даёт ссылку на поиск в Cambridge Dictionary. [Британское произношение schedule в Cambridge Dictionary](https://dictionary.cambridge.org/pronunciation/english/schedule)

Свободный чат доступен в верхнем меню. Базовый режим отвечает на типовые вопросы и поддерживает простые разговорные темы. Генеративные ответы работают через подключённый OpenRouter или встроенную языковую модель совместимого браузера. Если браузер поддерживает модель и ей нужна загрузка, её можно запустить по кнопке в свободном чате. [Требования Chrome к встроенному ИИ](https://developer.chrome.com/docs/ai/prompt-api#review_the_hardware_requirements)

### Academy Stars

Выбери **Academy Stars 1, 2, 3 или 4** и один из десяти основных юнитов в книге. Выбор применяется ко всем упражнениям и сохраняется между посещениями. На экране указан разворот Pupil’s Book, из которого взяты тема и слова урока Vocabulary. Реплики, загадки, карточки и образцы для произношения составлены для SpeakBuddy. Номер учебника соответствует уровню линейки Academy Stars. Настройка Pre-A1/A1 отдельно задаёт сложность реплик Бадди.

Пункт **Свободная практика** возвращает к общим темам и упражнениям. Для уже развёрнутого Cloudflare Worker повторите развёртывание, чтобы ИИ и фонетический анализ получили новый каталог.

## Локальный запуск

Двойной щелчок по `index.html` открывает демоверсию на GitHub Pages. Для запуска с компьютера на Windows дважды щёлкните `start-speakbuddy.cmd`. Он запустит Vite и откроет локальную страницу в браузере. Оставьте окно терминала открытым, пока пользуетесь ботом.

Для локального запуска нужен Node.js 24. Те же команды можно выполнить вручную из папки проекта.

```sh
npm ci
npm run dev
```

На Linux установите зависимости командой `ONNXRUNTIME_NODE_INSTALL_CUDA=skip npm ci`. Сборка сайта использует WebAssembly для озвучки в браузере.

Откройте `http://127.0.0.1:5173`. Подготовленные диалоги, озвучивание, угадывание и запись с воспроизведением доступны без ключей. `npm run build` проверяет TypeScript и собирает сайт в `dist/`.

## Подключение ИИ и фонетического анализа

Публичная версия работает на GitHub Pages. GitHub Actions собирает и публикует `dist/`. В настройках репозитория источником Pages служит GitHub Actions. Для облачных функций запросы идут в Cloudflare Worker. Он хранит ключи, ограничивает частоту обращений и требует отдельный код доступа к демонстрации.

### ИИ-диалог через OpenRouter

1. Для локальной проверки скопируйте `.dev.vars.example` в `.dev.vars`. Задайте `OPENROUTER_API_KEY` и случайный `DEMO_ACCESS_CODE` длиной от 16 символов. Во втором терминале запустите `npm run worker:dev` и обновите страницу.
2. Для сайта войдите в Cloudflare Wrangler через `npx wrangler login`, затем запустите `npm run worker:deploy`. Сохраните секреты командами `npx wrangler secret put OPENROUTER_API_KEY` и `npx wrangler secret put DEMO_ACCESS_CODE`.
3. В `Settings → Secrets and variables → Actions → Variables` задайте `VITE_API_BASE_URL` с HTTPS-адресом Worker. Запустите workflow публикации снова. Если изменился домен сайта, обновите `ALLOWED_ORIGINS` в `wrangler.toml`.
4. В режиме учителя введите код демонстрации и включите облачные функции. Попросите взрослого отвечать вымышленными данными.

Основная модель — `google/gemma-4-31b-it:free`. При недоступности модели сервер пробует `openrouter/free`. При исчерпании квоты или иной ошибке бот продолжает занятие по подготовленному сценарию. Идентификатор модели отображается в ответах, полученных через API. Модель работает с текстом и даёт краткую лексико-грамматическую подсказку.

[Модель Gemma в OpenRouter](https://openrouter.ai/google/gemma-4-31b-it:free) · [Ограничения OpenRouter](https://openrouter.ai/docs/api/reference/limits)

### Локальное произношение через Pronunciada

1. Установите Python и выполните `python -m pip install pronunciada`.
2. Запустите `pronunciada serve --host 127.0.0.1 --port 8765 --azure-compat`. При первом анализе инструмент может скачивать модель. Для демонстрации сделайте одну пробную запись заранее.
3. В `.dev.vars` задайте `PRONUNCIADA_LOCAL="true"`. Запустите `npm run worker:dev` и `npm run dev`, затем откройте `http://127.0.0.1:5173`. После записи нажмите «Проанализировать локально».

В этом режиме запись передаётся локальному процессу на том же компьютере. Баллы Pronunciada и Azure получены разными моделями и требуют самостоятельной калибровки для исследовательского сравнения. [Документация Pronunciada](https://github.com/moglearn/pronunciada/blob/main/docs/AZURE_COMPAT.md)

### Облачное произношение через Azure Speech

Укажите `AZURE_SPEECH_KEY`, `AZURE_SPEECH_RESOURCE` (имя ресурса Speech) и `DEMO_ACCESS_CODE` в `.dev.vars` для локальной проверки или сохраните их командой `npx wrangler secret put ИМЯ` при публикации Worker. Код и согласие на облачные функции вводятся в режиме учителя. Кнопка анализа отправляет в Azure короткую запись и заранее заданный текст фразы. Оценка `en-GB` отображается по словам. Доступность и тарификацию нужно проверить для своего ресурса. [Документация Microsoft](https://learn.microsoft.com/en-us/azure/ai-services/speech-service/how-to-pronunciation-assessment)

### Поиск британской IPA через Cambridge Dictionary

Чтобы запрашивать IPA для слов вне встроенной подборки, укажите лицензированный `CAMBRIDGE_API_KEY`, код подключённого словаря `CAMBRIDGE_DICTIONARY` и `DEMO_ACCESS_CODE` в `.dev.vars`. При публикации Worker сохраните ключ через `npx wrangler secret put CAMBRIDGE_API_KEY`. В режиме учителя введите код демонстрации и включите облачные функции. [Официальный Cambridge Dictionary API](https://dictionary.cambridge.org/develop)

## Сценарий технической демонстрации

1. Выберите **Academy Stars 2 → 1. In the wild** и откройте **AI Conversation**. Ответьте `There are two kangaroos.` и включите подсказку со словами юнита.
2. Откройте **Role Play**, сыграйте посетителя парка с дикими животными и посмотрите счётчики в режиме учителя. Для демонстрации грамматической подсказки выберите **Свободная практика → AI Conversation → Животные** и введите `My favourite animal is dog.`
3. Выберите **Academy Stars 3 → 6. Under the sea**. В **Describe the Picture** опишите карточки. В **Guess the Word** послушайте загадку, при необходимости спросите `What is the first letter?` и назовите слово.
4. В **Pronunciation Lab** прослушайте образец выбранного юнита, запишите фразу и воспроизведите запись. При подключённом анализе проверьте оценку, включив отображение баллов в режиме учителя.

Для статьи можно протоколировать тестовые реплики, тему, уровень, идентификатор модели, удержание темы и уместность подсказки. Техническая демонстрация показывает функции прототипа. Педагогическую эффективность необходимо проверять отдельно по данным апробации. Для демонстрации используйте обезличенные записи взрослых.
